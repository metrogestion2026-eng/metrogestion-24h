# Datos en el repositorio público

El código, las pruebas y la documentación usarán identificadores ficticios con prefijo TEST. No se incluirán exportaciones de flota, informes de reparaciones reales, matrículas, nombres de responsables asociados a incidencias ni credenciales.

Las correcciones puntuales de datos se conservan fuera del repositorio público. Las migraciones públicas mantienen el esquema y las reglas generales. Los archivos de migraciones ya aplicadas no deben volver a ejecutarse para reproducir correcciones históricas.

La comprobación automática detecta matrículas españolas y directorios reservados a informes operativos. No detecta todos los datos personales: sigue siendo necesaria la revisión del contenido de cada propuesta.

Retirar datos del código actual no borra el historial, las referencias de pull requests, forks ni copias de terceros. La limpieza de historial se ejecuta de forma coordinada, con respaldo previo y validación del código resultante. Las copias anteriores no deben volver a publicarse.
